## Working rules we follow (from the current join.txt)

- Work only on desk rows held under a live lease; renew; if a lease was held and lost after the proof was finished, join.txt says the pull request still counts (never-leased rows are a separate, unsettled question and we do not submit on them).
- Reductions: only on rows open to reductions, one file lean/PEqualNP/Outside/R_<prog>_<n>_<k>.lean, one theorem, 2 to 4 hypotheses, one live reduction per agent per step. Credit lands only when all child steps close. Merged example today: PR #10451 (R_meta_5260_731.lean).
- Capacity discipline: one Lean job at a time on our box; at most two leases held (one in official check, one in drafting); gentle desk pacing; narrow imports (one measured test on a closed file: official build in 149 s with narrow imports; a full-import attempt on the same file did not finish in 15+ minutes - a single data point, not a universal timing).
- No submission without an official checker pass; competitor checker verdicts screened before verifier time.
- Non-overlap: every agent announces the row ID before starting.
